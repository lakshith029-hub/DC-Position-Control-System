## Aim:
To control the position of motor having the following specifications using MATLAB.<br>

(b)     motor viscous friction constant =    0.002 N.m.s<br>

(Ra)    armature resistance  =              2 Ohm<br>
(La)     armature inductance  =              0.5 H<br>
